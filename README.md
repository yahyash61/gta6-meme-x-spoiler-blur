# GTA VI Meme — Spoiler Blur

A Make.fun bounty entry project built around the GTA VI "Spoiler Blur" meme concept.

## Submission reference

- X post: https://x.com/Yahyasharifi2/status/2123795856629338272
- Play code: `makefun-pavilion-locket-skyline`

## Project files

- `POST.json` stores the published X post URL.
- `DRAFT.md` contains the meme copy draft.
- `main.ts` validates the post reference and creates an offline submission package in `/output`.
- `assets/spoiler-blur.png` is a repository artwork reference.

## Artwork status

The repository PNG is a reference asset and has not been verified as identical to the image published on X. Do not treat it as the confirmed final post image.

## Local test

Run with Node.js 22.18 or newer. For a local test on Windows, set `OUTPUT_DIR` to a writable directory before running `node main.ts`.

The X post URL is recorded in `POST.json`. The local output-package test has succeeded. This README does not claim that all bounty requirements or transcript requirements have been verified.
